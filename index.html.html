University Course Registration

01 · The Rule

A student can register only if all four hold

Each condition gets a letter. Registration (R) succeeds only when every one of them is true, so they're joined with AND (∧):

F
Fees paid
P
Prerequisite completed
S
Seats available
T
No timetable clash
R
Registration succeeds
R ↔ ( F∧ P∧ S∧ T )

"Registration succeeds if and only if fees are paid AND the prerequisite is done AND a seat is open AND there's no timetable clash."
